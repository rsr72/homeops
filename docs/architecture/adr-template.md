# ADR Template

Use this lightweight template for important, durable technical decisions that have meaningful tradeoffs. It is not intended for every small implementation detail.

## ADR-NNNN: <Decision Title>

- Status: Proposed
- Date: YYYY-MM-DD

## Context
Describe the problem, constraint, or decision point that prompted this ADR.

## Decision
State the chosen approach clearly and briefly.

## Alternatives Considered
List the main options and why they were not selected.

## Consequences
Summarize the expected benefits, costs, risks, and tradeoffs.

## Security/Privacy (optional)
Include this section when the decision has relevant security or privacy implications.

## Cost/Operational Impact (optional)
Include this section when the decision has relevant cost, reliability, or operational impact.

## Related Issues/Docs
Reference relevant issues, pull requests, or documentation.
